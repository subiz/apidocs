## Start here

Connect customer records, conversations, and messages with your own systems. Users are customers; agents are the staff who support them. The documented contracts were checked against Subiz source code.

1. Read [Authentication](/docs/get-started/authentication) to prepare your access token.
2. Follow [Send Message](/docs/api-reference/messages/send) to construct a request.

## Before you begin

You need a valid access token and the ID of an existing conversation your integration is allowed to access. Keep the token on your server. The samples use placeholder values; replace them before running a request.

## Integration workflow

1. [Create a customer](/docs/api-reference/users/create) or retrieve an existing record.
2. [Read the conversation](/docs/api-reference/conversations/retrieve).
3. [Invite an agent](/docs/api-reference/conversations/invite-agent) and [assign ownership](/docs/api-reference/conversations/assign-agent).
4. [Send a message](/docs/api-reference/messages/send).
5. [Receive webhook events](/docs/webhooks/receiving) to keep your system updated.

## Scope

The API gateway source confirms request handling and the response type. Sending permissions, channel restrictions, and delivery rules are enforced by downstream services and are not fully specified here. No live message was sent while preparing these docs.
