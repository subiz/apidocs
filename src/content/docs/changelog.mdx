## Reading API versions

Each endpoint page displays its API route version, such as **API 4.0** or **API 4.1**, above the title. Use the exact HTTP method and URL shown on that page. A different version number is not a reason to replace the version in an existing URL.

Shared guides list the versions they cover. Webhook receiving and payload pages describe delivery to your server, so they are not tied to a version in a Subiz API route.
