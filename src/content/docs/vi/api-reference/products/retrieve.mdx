Dùng endpoint này để đọc trạng thái hiện tại của sản phẩm, ví dụ trước khi cập nhật.

## Yêu cầu

Gửi yêu cầu `GET` không có body.

| Tham số | Kiểu | Mô tả |
| --- | --- | --- |
| `accid` (đường dẫn) | string | ID tài khoản của bạn. |
| `pid` (đường dẫn) | string | ID sản phẩm Subiz. |

Agent sở hữu token cần quyền xem sản phẩm. Để tìm sản phẩm theo ID riêng của bạn hoặc SKU, dùng [Lấy danh sách sản phẩm](/docs/vi/api-reference/products/list) với `source_id` hoặc `sku`.

## Phản hồi

Yêu cầu thành công trả HTTP `200` cùng sản phẩm. Một số trường:

```json
{
  "id": "product_example",
  "account_id": "account_example",
  "source_id": "shop-sku-mug-01",
  "name": "Ceramic mug",
  "sku": "MUG-01",
  "price": 120000,
  "currency": "VND",
  "stock": 25,
  "availability": "in_stock",
  "visibility": "published",
  "product_group_id": "product_example",
  "num_variants": 1,
  "other_variants": [
    {
      "id": "product_variant_example",
      "name": "Ceramic mug",
      "sku": "MUG-01-BLUE",
      "price": 120000,
      "product_group_id": "product_example"
    }
  ],
  "updated": 1763107200000
}
```

Xem [Định dạng sản phẩm](/docs/vi/products/format) để biết mọi trường. Endpoint này còn trả về:

| Trường | Mô tả |
| --- | --- |
| `num_variants` | Số sản phẩm khác trong cùng nhóm biến thể. |
| `other_variants` | Tối đa năm sản phẩm trong số đó. |

Nếu không có sản phẩm nào có ID này, yêu cầu trả lỗi không tìm thấy. Xem [Xử lý lỗi](/docs/vi/get-started/errors).

## Yêu cầu HTTP

Thay `YOUR_ACCID`, `YOUR_PID` và `YOUR_ACCESS_TOKEN` bằng giá trị của bạn.
