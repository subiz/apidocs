## Trước khi bắt đầu

Dùng [Bearer access token](/docs/vi/get-started/authentication) của đúng tài khoản. Thay toàn bộ chỗ điền `YOUR_…` bằng ID thực. Yêu cầu thay đổi dữ liệu sẽ tác động lên dữ liệu thật.

## Xác định khách hàng

Thay `uid` bằng ID khách hàng. Dùng yêu cầu này để đọc hồ sơ hiện tại trước khi đồng bộ thay đổi.

## Kết quả

Gateway gọi dịch vụ khách hàng và trả kết quả dưới dạng JSON. Xử lý trường hợp không tìm thấy hoặc không có quyền trước khi đọc thuộc tính. Xem [Cập nhật khách hàng](/docs/vi/api-reference/users/update).

## Yêu cầu HTTP

Thay các giá trị `YOUR_…` bằng thông tin của bạn. Gửi các header bên dưới và body JSON nếu có. Kiểm tra mã trạng thái HTTP trước khi sử dụng phản hồi.
