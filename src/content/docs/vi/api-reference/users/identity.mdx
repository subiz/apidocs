Dùng endpoint này khi bạn biết định danh của khách hàng trên một kênh, như hồ sơ Facebook của họ trên trang của bạn, nhưng chưa biết ID user Subiz. Endpoint trả về khách hàng đã có, hoặc tạo mới nếu chưa có.

## Định danh kênh

Định danh kênh gồm ba phần, đều nằm trong đường dẫn URL:

| Tham số | Kiểu | Mô tả |
| --- | --- | --- |
| `accid` (đường dẫn) | string | ID tài khoản của bạn. |
| `channel` (đường dẫn) | string | Kênh, như `facebook` hoặc `zalo`. |
| `source` (đường dẫn) | string | Trang hoặc tài khoản đã kết nối trên kênh đó, như ID trang Facebook. |
| `id` (đường dẫn) | string | ID hồ sơ của khách hàng trên kênh đó. |

Dùng giá trị từ tích hợp đã kết nối. Không đặt ID user Subiz vào `id`. Không có body.

## Tìm mà không tạo

Dùng `GET` trên cùng đường dẫn để tìm khách hàng mà không tạo mới:

```http
GET https://api.subiz.com.vn/4.1/accounts/YOUR_ACCID/contact-profiles/YOUR_CHANNEL/sources/YOUR_SOURCE/YOUR_ID
Authorization: Bearer YOUR_ACCESS_TOKEN
```

Dùng `POST`, ở cuối trang này, để tìm hoặc tạo khách hàng.

## Phản hồi

Cả hai phương thức đều trả HTTP `200` cùng khách hàng. Một số trường:

```json
{
  "id": "user_example",
  "account_id": "account_example",
  "channel": "facebook",
  "channel_source": "page_example",
  "profile_id": "profile_example",
  "attributes": [
    {
      "key": "fullname",
      "text": "Alex Example"
    }
  ]
}
```

Lưu `id` của Subiz cùng với định danh kênh. Dùng `id` để [lấy thông tin](/docs/vi/api-reference/users/retrieve) hoặc [cập nhật](/docs/vi/api-reference/users/update) khách hàng.

Subiz có thể chuẩn hóa hoặc gộp định danh khách hàng. Nếu việc tìm kiếm tạm thời thất bại, hãy thử lại thay vì tạo một khách hàng riêng bằng [Tạo khách hàng](/docs/vi/api-reference/users/create).

## Gửi tin mà không cần tìm trước

Để nhắn tin cho khách hàng theo định danh kênh, bạn có thể bỏ qua bước này. [Gửi tin nhắn cho khách hàng](/docs/vi/api-reference/messages/send-to-user#xác-định-khách-hàng) nhận trực tiếp `channel`, `channel_source` và `profile_id`.

## Yêu cầu HTTP

Thay `YOUR_ACCID`, `YOUR_CHANNEL`, `YOUR_SOURCE`, `YOUR_ID` và `YOUR_ACCESS_TOKEN` bằng giá trị của bạn.
