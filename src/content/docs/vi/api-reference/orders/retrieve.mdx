Dùng endpoint này để đọc trạng thái hiện tại của đơn hàng, ví dụ trước khi cập nhật hoặc sau khi thanh toán.

## Yêu cầu

Gửi yêu cầu `GET` không có body.

| Tham số | Kiểu | Mô tả |
| --- | --- | --- |
| `accid` (đường dẫn) | string | ID tài khoản của bạn. |
| `oid` (đường dẫn) | string | ID đơn hàng Subiz. |

Nhân viên sở hữu token cần có quyền xem đơn hàng.

## Phản hồi

Yêu cầu thành công trả HTTP `200` cùng đơn hàng. Một số trường:

```json
{
  "id": "order_example",
  "account_id": "account_example",
  "number": "1001",
  "source_id": "crm-1001",
  "status": "closed",
  "payment_status": "paid",
  "currency": "VND",
  "user": {
    "id": "user_example"
  },
  "items": [
    {
      "id": "item_example",
      "quantity": 2,
      "product": {
        "name": "Ceramic mug",
        "sku": "MUG-01",
        "price": 120000
      },
      "total": 240000
    }
  ],
  "total": 270000,
  "payment_made": 270000,
  "closed": 1763193600000,
  "updated": 1763193600000
}
```

Xem [Định dạng đơn hàng](/docs/vi/orders/format) để biết mọi trường. `closed` được đặt khi đơn chuyển sang `closed` hoặc `canceled`.

Nếu không có đơn nào có ID này, yêu cầu trả lỗi không tìm thấy. Xem [Xử lý lỗi](/docs/vi/get-started/errors).

## Yêu cầu HTTP

Thay `YOUR_ACCID`, `YOUR_OID` và `YOUR_ACCESS_TOKEN` bằng giá trị của bạn.
