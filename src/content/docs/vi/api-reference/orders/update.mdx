Dùng endpoint này để thay đổi đơn hàng, ví dụ chốt đơn khi khách hàng xác nhận, hoặc hủy đơn.

## Luôn liệt kê các trường cần thay đổi

Thêm `x-fields` vào query string với danh sách các trường bạn gửi, phân tách bằng dấu phẩy:

```http
POST https://api.subiz.com.vn/4.0/accounts/YOUR_ACCID/orders/YOUR_OID?x-fields=status,note
```

Chỉ các trường được liệt kê mới thay đổi.

**Nếu không có `x-fields`, body sẽ thay thế toàn bộ đơn hàng.** Mọi trường bạn bỏ trống sẽ bị xóa, kể cả mặt hàng, giao hàng và ghi chú. Nếu buộc phải gửi đơn đầy đủ, hãy [đọc đơn](/docs/vi/api-reference/orders/retrieve) trước rồi gửi lại kèm thay đổi.

## Body yêu cầu

Gửi giá trị mới của các trường đã liệt kê trong `x-fields`:

```json
{
  "status": "closed",
  "note": "Customer confirmed by phone."
}
```

Các thay đổi thường gặp:

| Trường | Ghi chú |
| --- | --- |
| `status` | `open`, `unconfirmed`, `closed` hoặc `canceled`. |
| `items` | Thay thế mọi dòng. Tổng tiền được tính lại. |
| `shipping` | Thay thế thông tin giao hàng. |
| `note`, `private_note` | Ghi chú của đơn. |
| `salesperson` | ID agent phụ trách đơn. |
| `cancellation_note`, `cancellation_code` | Lý do khi hủy. |

Đừng đưa `source_id` vào body cập nhật. Nếu nó trùng với đơn khác, đơn đó sẽ bị cập nhật thay vì đơn này.

## Subiz làm gì

- Tính lại `subtotal`, `total_tax`, `total`, `payment_made` và `payment_status`. Giá trị bạn gửi cho các trường này bị bỏ qua.
- Giữ nguyên `created`, `created_by`, cùng thẻ và agent của đơn.
- Khi trạng thái chuyển sang `closed` hoặc `canceled`, đặt `closed`. Với `canceled`, đặt thêm `cancelled_at` và `cancelled_by`.
- Nếu sau khi cập nhật đơn ở trạng thái `closed` hoặc `canceled` và có mã vận đơn, Subiz sẽ thử hủy vận đơn với đơn vị vận chuyển. Điều này cũng xảy ra khi bạn sửa một đơn đã đóng từ trước. Đừng cập nhật đơn đã đóng có vận đơn đang hoạt động trừ khi bạn chủ ý làm vậy.

## Phản hồi

Yêu cầu thành công trả HTTP `200` cùng toàn bộ đơn hàng đã cập nhật. Một số trường:

```json
{
  "id": "order_example",
  "status": "closed",
  "note": "Customer confirmed by phone.",
  "payment_status": "unpaid",
  "total": 270000,
  "closed": 1763193600000,
  "updated": 1763193600000
}
```

## Lỗi

| Vấn đề | Kết quả |
| --- | --- |
| Không có đơn nào có ID này | Lỗi không tìm thấy. |
| `status` không thuộc bốn giá trị | Lỗi dữ liệu không hợp lệ cho `status`. |

Xem [Xử lý lỗi](/docs/vi/get-started/errors).

## Yêu cầu HTTP

Thay `YOUR_ACCID`, `YOUR_OID` và `YOUR_ACCESS_TOKEN` bằng giá trị của bạn.
