Dùng endpoint này để đặt người phụ trách hội thoại, tức `assignee`, là một agent cụ thể. Dùng khi chuyển giao, ví dụ khi CRM của bạn quyết định nhân viên bán hàng nào chăm sóc khách hàng.

## Trước khi bắt đầu

- Lấy [Bearer access token](/docs/vi/get-started/authentication) và ID tài khoản.
- Lấy ID của một agent có sẵn trong tài khoản.

## Body yêu cầu

| Trường | Kiểu | Mô tả |
| --- | --- | --- |
| `accid` (đường dẫn) | string | ID tài khoản của bạn. |
| `cid` (đường dẫn) | string | Hội thoại cần giao. |
| `assignee` | string | ID agent sẽ phụ trách hội thoại. |

```json
{
  "assignee": "agent_example"
}
```

Route này cập nhật thông tin hội thoại. Khi giao việc, chỉ gửi `assignee`.

## Phản hồi

Yêu cầu thành công trả HTTP `200` cùng `Conversation` đã cập nhật. Một số trường:

```json
{
  "id": "conversation_example",
  "account_id": "account_example",
  "state": "active",
  "assignee": "agent_example"
}
```

Khi người phụ trách thay đổi, Subiz phát sự kiện `conversation_assigned`. Webhook đã đăng ký sẽ nhận được; xem [Hội thoại được giao](/docs/vi/webhooks/payloads#hội-thoại-được-giao).

## Giao việc không phải là tham gia

Giao agent không thêm họ vào `members`. Nếu agent cũng cần tham gia, hãy [mời agent](/docs/vi/api-reference/conversations/invite-agent) nữa.

## Bỏ giao việc

Gửi `assignee` rỗng và thêm `x-fields=assignee` vào query string:

```http
POST https://api.subiz.com.vn/4.0/accounts/YOUR_ACCID/conversations/YOUR_CID?x-fields=assignee
Authorization: Bearer YOUR_ACCESS_TOKEN
Content-Type: application/json

{
  "assignee": ""
}
```

`x-fields` liệt kê các trường cần cập nhật. Nếu thiếu, giá trị rỗng được coi là "không cung cấp" và người phụ trách giữ nguyên. Bỏ người phụ trách sẽ phát sự kiện `conversation_unassigned`.

## Phân bổ tự động là việc khác

`POST /4.1/conversations/{cid}/assign` yêu cầu Subiz chạy lại phân bổ tự động. Nó không nhận ID agent. Dùng endpoint trên trang này để chọn một agent cụ thể.

## Yêu cầu HTTP

Thay `YOUR_ACCID`, `YOUR_CID`, `YOUR_AGENT_ID` và `YOUR_ACCESS_TOKEN` bằng giá trị của bạn.
