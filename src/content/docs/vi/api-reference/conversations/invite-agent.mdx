Dùng endpoint này để đưa một agent khác vào hội thoại, ví dụ một chuyên viên cần hỗ trợ. Agent đó phải đã có tài khoản Subiz.

## Mời, giao hay tự động phân bổ?

| Bạn muốn | Dùng |
| --- | --- |
| Thêm agent làm người tham gia | Endpoint này. |
| Giao cho agent phụ trách hội thoại | [Giao agent](/docs/vi/api-reference/conversations/assign-agent). |
| Thêm agent mới vào tài khoản | Ứng dụng Subiz. Endpoint này không tạo agent hay gửi lời mời tham gia tài khoản. |
| Để Subiz tự chọn agent | Phân bổ tự động. Endpoint này luôn dùng đúng agent bạn chỉ định. |

Mời agent không thay đổi `assignee` của hội thoại.

## Body yêu cầu

Body là một thành viên hội thoại.

| Trường | Kiểu | Mô tả |
| --- | --- | --- |
| `cid` (đường dẫn) | string | ID hội thoại. |
| `type` | string | Đặt là `agent`. |
| `id` | string | ID của agent có sẵn cần mời. |

```json
{
  "type": "agent",
  "id": "agent_example"
}
```

Subiz lấy tài khoản từ [access token](/docs/vi/get-started/authentication) và hội thoại từ đường dẫn.

## Phản hồi

Yêu cầu thành công trả HTTP `200` cùng một đối tượng rỗng:

```json
{}
```

Subiz ghi một sự kiện `conversation_invited` vào hội thoại. Để xác nhận kết quả, [lấy thông tin hội thoại](/docs/vi/api-reference/conversations/retrieve) và kiểm tra agent đã có trong `members`:

```json
{
  "id": "agent_example",
  "type": "agent",
  "conversation_id": "conversation_example",
  "membership": "active"
}
```

## Yêu cầu HTTP

Thay `YOUR_CID` bằng ID hội thoại, `YOUR_AGENT_ID` bằng ID agent và `YOUR_ACCESS_TOKEN` bằng token của bạn.
