## Lấy access token

1. Đăng nhập Subiz và mở [Mã truy cập cá nhân](https://app.subiz.com.vn/apikey).
2. Nhấn **Tạo mã truy cập**.
3. Chọn **Tài khoản** cần kết nối. Nhập **Ghi chú**, ví dụ `CRM integration`, và chọn **Thời hạn hết hạn**.
4. Nhấn **Tạo mã** để xác nhận.
5. Nhấn **Sao chép mã** và lưu an toàn trước khi đóng hộp thoại.

**Token chỉ hiển thị một lần.** Nếu làm mất, hãy tạo token mới. Mỗi token thuộc tài khoản đã chọn khi tạo.

Yêu cầu gửi bằng token này hoạt động với tư cách nhân viên của bạn trong tài khoản đó. Quyền của nhân viên vẫn được áp dụng; tạo token không cấp thêm quyền.

## Kiểm tra access token

Trong công cụ gọi API, gửi yêu cầu sau. Thay `YOUR_ACCESS_TOKEN` bằng token vừa sao chép. Không cần body.

```http
GET https://api.subiz.com.vn/4.1/me
Authorization: Bearer YOUR_ACCESS_TOKEN
```

**Kết quả mong đợi:** `200 OK` cùng hồ sơ nhân viên của bạn dưới dạng JSON. Ví dụ dưới đây hiển thị một số trường với giá trị mẫu:

```json
{
  "id": "YOUR_AGENT_ID",
  "account_id": "YOUR_ACCOUNT_ID",
  "fullname": "Example Agent"
}
```

Kiểm tra `account_id` trùng với tài khoản bạn muốn kết nối. `id` là nhân viên đang gửi yêu cầu. Kiểm tra thành công chỉ xác nhận quyền truy cập `/me`, không phải mọi thao tác API.

Yêu cầu kiểm tra token cũng được tính vào [giới hạn sử dụng](/docs/vi/get-started/usage-limits). Nếu `/me` trả `429`, hãy chờ hết khoảng `Retry-After` rồi mới thử lại.

## Thay thế hoặc thu hồi token

Để thay token hết hạn hoặc bị mất, tạo token mới và cập nhật tích hợp. Kiểm tra token mới bằng `/me`, sau đó xóa token cũ nếu nó vẫn còn trong danh sách.

Để thu hồi token, mở [Mã truy cập cá nhân](https://app.subiz.com.vn/apikey), mở menu **…** của token, chọn **Xóa mã truy cập** và xác nhận. Không thể hoàn tác thao tác xóa. Nếu token bị lộ, hãy thu hồi trước khi tạo token thay thế.

Lưu token phía máy chủ, chẳng hạn trong biến môi trường. Không đặt token trong mã trình duyệt, kho mã nguồn công khai hoặc URL.

## Nếu xác thực thất bại

Kiểm tra token có đúng, còn hạn, chưa bị xóa và thuộc tài khoản đang truy cập. Giữ nguyên tiền tố `Bearer `, gồm cả dấu cách.

Lỗi xác thực có thể trả HTTP `400`. Đọc [phản hồi lỗi JSON](/docs/vi/get-started/errors) trước khi thử lại.

## Bước tiếp theo

[Gửi tin nhắn](/docs/vi/api-reference/messages/send) bằng token và ID hội thoại đã có.
