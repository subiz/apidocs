## Đọc phiên bản API

Mỗi trang endpoint hiển thị phiên bản đường dẫn, chẳng hạn **API 4.0** hoặc **API 4.1**, phía trên tiêu đề. Dùng đúng phương thức HTTP và URL trên trang. Không tự thay phiên bản trong URL chỉ vì thấy số phiên bản khác.

Hướng dẫn chung liệt kê các phiên bản được đề cập. Các trang nhận webhook và payload mô tả dữ liệu gửi đến máy chủ của bạn, nên không phụ thuộc phiên bản đường dẫn API Subiz.

## 2026-11-14 — Cập nhật tài liệu

**Chỉ thay đổi tài liệu · Không công bố thay đổi hành vi API**

- Thêm nhãn phiên bản API trên từng trang.
- Thêm nhật ký thay đổi để ghi nhận cập nhật tài liệu và thay đổi API đã xác nhận sau này.
- Bổ sung hướng dẫn webhook tiếng Anh về xác minh chữ ký, xử lý chuyển phát và payload sự kiện khách hàng. Bản dịch webhook tiếng Việt đang chờ cập nhật.
- Thêm đề mục Đơn hàng và Sản phẩm, chờ bài viết được xác minh.

Mục này không khẳng định API nào được ra mắt hay ngừng hỗ trợ vào ngày này. Chưa có thao tác API 4.2 nào được mô tả.

## Công bố thay đổi API

Chưa có lịch sử phát hành API được xác nhận từ nguồn chính thức trong tài liệu. Các mục sau này sẽ nêu phiên bản và thao tác bị ảnh hưởng, ngày có hiệu lực, thay đổi có phá vỡ tương thích hay không và các bước chuyển đổi cần thiết.
