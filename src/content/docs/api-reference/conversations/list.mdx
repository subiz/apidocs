## Before you begin

Use a [Bearer access token](/docs/get-started/authentication) for the intended account. Replace all `YOUR_…` placeholders with real identifiers. Mutation requests change real data.

## Find a customer's conversations

Use `user_id` to select a customer. The example requests up to 20 conversations. The service defaults a zero or omitted limit to 20 and caps positive limits at 200.

| Query parameter | Type | Purpose |
| --- | --- | --- |
| `user_id` | string | Customer whose conversations you need. |
| `agent_id` | string | Agent filter for the service's agent-listing branch. |
| `limit` | integer | Requested number of results. |

User credentials are restricted to their own user identity. Unknown and connector credentials are rejected by this service method. Filter combinations follow service-specific branches; do not assume all filters compose freely.

## Result

The response contains a `conversations` array. Read an individual conversation with [Retrieve a conversation](/docs/api-reference/conversations/retrieve). This route does not establish an offset-based pagination contract or a `next_cursor` response field.
