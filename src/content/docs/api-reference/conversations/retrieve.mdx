## Before you begin

Use a [Bearer access token](/docs/get-started/authentication) for the intended account. Replace all `YOUR_…` placeholders with real identifiers. Mutation requests change real data.

## Conversation context

Replace `cid` with an existing conversation ID. The gateway forwards the authenticated account and conversation ID to `GetConversation`.

## Result

Inspect the conversation returned by the service before choosing the next action. [Invite an agent](/docs/api-reference/conversations/invite-agent) adds participation; [Assign an agent](/docs/api-reference/conversations/assign-agent) sets ownership.
