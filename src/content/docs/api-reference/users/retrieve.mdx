## Before you begin

Use a [Bearer access token](/docs/get-started/authentication) for the intended account. Replace all `YOUR_…` placeholders with real identifiers. Mutation requests change real data.

## Identify the customer

Replace `uid` with the customer ID. Use this request to read the customer's current profile before synchronizing changes.

## Result

The gateway calls the user service and returns its result as JSON. Handle missing records and permission failures before reading attributes. Related: [Update a user](/docs/api-reference/users/update).
