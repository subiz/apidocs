Use this endpoint to read the current state of a product, for example before updating it.

## Request

Send a `GET` request with no body.

| Parameter | Type | Description |
| --- | --- | --- |
| `accid` (path) | string | Your account ID. |
| `pid` (path) | string | Subiz product ID. |

The token's agent needs permission to read products. To find a product by your own ID or SKU, use [List products](/docs/api-reference/products/list) with `source_id` or `sku`.

## Response

A successful request returns HTTP `200` with the product. Selected fields:

```json
{
  "id": "product_example",
  "account_id": "account_example",
  "source_id": "shop-sku-mug-01",
  "name": "Ceramic mug",
  "sku": "MUG-01",
  "price": 120000,
  "currency": "VND",
  "stock": 25,
  "availability": "in_stock",
  "visibility": "published",
  "product_group_id": "product_example",
  "num_variants": 1,
  "other_variants": [
    {
      "id": "product_variant_example",
      "name": "Ceramic mug",
      "sku": "MUG-01-BLUE",
      "price": 120000,
      "product_group_id": "product_example"
    }
  ],
  "updated": 1763107200000
}
```

See [Product format](/docs/products/format) for every field. This endpoint also returns:

| Field | Description |
| --- | --- |
| `num_variants` | Number of other products in the same variant group. |
| `other_variants` | Up to five of those products. |

If no product has this ID, the request returns a not-found error. See [Errors](/docs/get-started/errors).

## HTTP request

Replace `YOUR_ACCID`, `YOUR_PID`, and `YOUR_ACCESS_TOKEN` with your values.
